# Front-page story slideshow

The homepage uses 12 distinct images: the existing `assets/images/community-detail.webp`, plus 11 new illustrations generated using the built-in imagegen tool. All assets are local.

## Behaviour

- Five-second viewing interval, gentle zoom and 650 ms crossfade.
- Automatically shuffled rounds: all 12 images appear before the next round, with no immediate repeat at the boundary.
- Click the main image, use arrow keys, or swipe on a touch screen. Number counters, navigation dots, and separate previous/next and pause/play buttons are omitted.
- Reduced-motion preference disables autoplay and image transitions; manual image selection remains available.
- Preloads the next image, pauses offscreen or in a hidden tab, skips failed image loads and cleans up timers/listeners on route changes.
- Captions and controls follow the site's Bangla/English preference.

Code: `assets/js/hero-slideshow.js`. Styles: `assets/css/hero-slideshow.css`.
